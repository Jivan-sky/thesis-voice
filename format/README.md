# 本地格式规格（localization）

## 为什么有这个目录

本 skill 只管**怎么写**（句子、段落、论证、批注），不管**排成什么样**。

字体、字号、行距、页边距、图题位置、参考文献著录格式——这些是各校各模板的事实，不是写作规律。把它们写死在 skill 里会有两个后果：

1. 别人装了用，拿到的是某一所学校的版式，直接被带偏；
2. 学校模板改版后，skill 里的值变成错的，还没人知道该改哪。

所以格式单独放这里，**由使用者注入，Agent 负责解析并记录**。

## 文件

| 文件 | 用途 |
| --- | --- |
| `本地格式规格.md` | 当前使用的格式规格。默认是空模板（第 1 行写着"未填写"） |

一份模板一个文件。换学校、换模板就新建 `本地格式规格_XX学校.md`，不要覆盖，旧稿可能还在用旧格式。

## Agent 的操作约定

**激活本 skill 时，先看 `format/本地格式规格.md`：**

- 第 1 行是 `# 版本：未填写`，或表格里大量 `〔未填写〕` → **说明还没本地化**。此时：
  - 涉及版式的问题（字号、字体、行距、题注、著录格式）**不要凭经验回答，也不要给默认值**；
  - 向使用者索取：学校模板 docx、规范 PDF、或直接口述；
  - 拿到后逐项填进表里，标注依据（第几页、哪条），拿不准的写"待确认"。
- 已填写 → 每次写稿、改稿、自检都读它，**与 SKILL.md 或 references 里任何示例冲突时，以它为准**。

## 不要把格式写回 skill

解析出来的字体字号，只写进 `format/` 下的文件，**不要写进 `SKILL.md`、`references/`、README**。那些是给别人复用的通用内容。

同理：`references/04-批注类型学.md` 里引用的"老师要求引号换字体"只是**病灶类型**的举例，不绑定具体字体。

## 什么时候不该用这个目录

- 只是问"这句话怎么改" —— 不需要格式，别去碰它。
- 只是问"逻辑通不通" —— 同上。
- 需要生成 docx 并套模板 —— 那是排版工具的事；本目录只提供"应该是什么样"的事实依据。


## 模板与本地文件

- `本地格式规格.template.md` —— 公开模板，进仓库，**不要直接填它**。
- `本地格式规格.md` —— 你的本地文件，从模板复制而来，已在 `.gitignore` 里，不进仓库、`git pull` 不覆盖。

```bash
cp 本地格式规格.template.md 本地格式规格.md
```
