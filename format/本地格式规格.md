# 版本：未填写

> **这个文件默认是空模板，属于设计而非缺陷。**
> 本 skill 不假设任何学校的版式要求。字体、字号、行距、页边距、题注位置这些，
> 各校各模板不同，写死在 skill 里只会误导别人。
>
> 正确用法：使用者把学校的格式要求（模板 docx / 规范 PDF / 口述）交给 Agent，
> Agent 解析后**逐项填进下面的表**，并标注依据。之后每次写稿、改稿、自检都以这份为准。

## 填写规则

1. **只写事实**。没核对过的项写"待确认"，不要猜。
2. **每一项标注依据**。来自模板第几页、哪条规范，写清楚，方便复核。
3. **与 skill 示例冲突时，以本文件为准**。
4. 换学校、换模板时，**新建一份**（如 `本地格式规格_XX学校.md`），不要覆盖旧的——旧稿可能在用旧格式。
