# 01 指纹与诊断

## 三套基准（单位：汉字）

| 指标 | **学位论文正文**（n=6） | 期刊正文（n=13） | 摘要（n=19） |
| --- | --- | --- | --- |
| 平均句长 | **52.8**（48.7–56.1） | 64.0（49.9–83.0） | 73.4 |
| >50 字长句占比 | **40.6%**（34.8–43.4） | 52.2%（39.1–65.1） | ≥80 字句占 33% |
| ≤15 字短句占比 | 3.4%（2.0–6.3） | 9.3%（4.6–16.4） | 1.7% |
| 句长变异 CV | **0.70**（0.56–0.86） | 0.80（0.60–1.07） | 1.00 |
| 相邻句长差 | **30.4**（25.0–37.0） | 49.2（37.7–64.2） | 63.0 |
| "A、B、C"三项串联/千字 | 1.5（0.6–2.7） | 2.9（0.2–6.0） | 1.3 |
| 硬空词/千字 | 0.4（0.2–0.7） | 0.6（0.0–1.8） | 0.4 |
| 数字/千字 | **40.8**（30.3–68.4） | 26.5（6.0–38.2） | 45.4 |
| "本文"/千字 | 1.0（0.2–1.7） | 0.8（0.0–2.5） | 2.7 |
| 分号/千字 | 1.0（0.5–1.6） | 3.3（1.5–7.8） | 3.3 |

**为什么学位论文比期刊句短**：期刊要在 3–5 页塞完，靠分号和插入语压缩；学位论文有整章篇幅，用短句换"读得下去"。**写学位论文按左边一列，投稿按中间一列。**

## 怎么读这些数

**平均句长**——不是越长越好。低于 45 说明一个句子装不下"条件+机制+结果"，论述被切成清单；高于 85 说明一句里塞了太多并列，读者要回读。

**相邻句长差**——比平均句长更能反映"读起来闷不闷"。它衡量下一句和上一句差多少字。31 字是学位论文的中位数，低于 24 就是匀速流水句。

**句长 CV**——全局起伏。低于 0.55 基本可以判定"每句都差不多长"，这是机器感的头号来源。

**三项串联**——「A、B、C」出现频率。它不是不能用，而是**用多了说明你在列清单而不是讲关系**。超过 4.5/千字，通常对应"该论证的地方写了枚举"。

**硬空词**——赋能/助力/极大/大幅/日益/不可或缺/一站式这类。合格论文每 2500 字才出现一个。**但注意：它不是普适判据。**"赋能"后面紧跟具体对象时是站得住的（"AI 赋能主题式学习服务"）；真正空转的是没有宾语的"数字化浪潮""全面提升"。

**数字密度**——学位论文 40.8/千字。纯正文段（不含表格）里数字为 0，几乎一定意味着"这段在讲设计意图，没在讲事实"。

## 诊断五步

1. 跑 `voice_check.py`，看 11 项里几项偏离。
2. **先看"相邻句长差"和"句长 CV"**。这两项偏离，说明问题在节奏，不在用词，改词没用。
3. 看"结果句无数字"清单。有一条就说明这段在凭印象写。
4. 看"模板化段首"和"相邻同头句"。连续以"本章/本节/该系统"开头，说明段落没有各自的论点。
5. 看"高频 4 字串"。同一个四字组合出现 3 次以上（如"功能需求""实体关系"），通常是概念没分层，一直在同一层打转。

## 不同章节的合理范围

同一个 45–85 的区间不是所有章都适用：

| 章节 | 均句 | 数字密度 | 说明 |
| --- | --- | --- | --- |
| 摘要 | 70–80 | 高（有结果就给） | 单句上限 150 字 |
| 绪论·背景 | 45–60 | 低（引用别人的数据要给出处） | 别写成行业报告 |
| 绪论·研究现状 | 55–75 | 中 | 年份+人名+方法+作用，这类句子必然长 |
| 需求分析 | 45–60 | 中（规模、并发、阈值） | 表格可以有，但每类需求要有一段解释 |
| 概要设计 | 50–65 | 低 | 分层说明，每层一段 |
| 详细设计 | 50–70 | 中（表结构、字段数、接口数） | 最容易写成代码注释，要用"为什么这样设计"救回来 |
| 测试 | 45–60 | **很高**（必须） | 每个用例有输入、预期、实际、结论 |
| 小结 | 45–55 | 低 | 四件事：做了什么、用了什么、得到什么、给下一章留什么钩子 |

## 语料分级（按语言，不按学术价值）

- **A 结构与句式可学**：孙鸿博、宋婧、邓浩霖、周毅、郭玮、董涛（学位论文）；谢巨龙、郭利荣、焦文、雒鹏鑫、要鑫、赵翔、刘泰成（期刊）
- **B 骨架可学、句法一般**：许宏新、何一苇、蒋明君、高宇德、梁鑫昊、冀勇、李粟、李艳茹、龚厚骅、王丽丽、王宇辰、谢圣富
- **C 别学腔调**：李致远（"创新性解决方案"密集、正文无机制）、刘杰（硬空词密度最高）、何一苇摘要（连续三段"旨在…"）

例外提醒：**雒鹏鑫的句长起伏只有 1.96 倍**（最平的一篇），但靠"冒号定义／首先—随后—最终"撑住节奏。说明节奏有两套实现：句长，或显式结构词。**两者至少要有一个**；都缺，先补句长（结构词好补，句长难改）。
