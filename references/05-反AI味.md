# 05 反 AI 味

"AI 味"不是一个东西，是六个可分离的症状。逐条可查、可改。

---

## 症状 1：句长匀速

**判据**：句长 CV < 0.55，或相邻句长差 < 24。

**为什么像机器**：模型倾向于每句 30–45 字，长度分布是窄带；人写论文是"长句撑论证 + 短句收束"，方差大。

**改法**：
1. 每段至少一句 60 字以上——把"条件 + 机制 + 结果"塞进一句。
2. 每段至少一句 15 字以内——下判断、换主语、收束。
3. 作者出场那句必须最短。

```
差：文档上传和编译需要保持任务可恢复。任务进入队列后，系统先保存文档版本和任务记录，再启动解析与模型调用；HTTP 请求不等待完整编译结束。（30.3 字/句，4 句）

好：文档上传与编译是一条可能中断的长链路，因此系统把"文档版本—编译任务—阶段产物"三者分开保存：任务进入队列时先落库文档版本和任务记录，再启动解析与模型调用，HTTP 请求在任务入队后即返回，不等待整条链路结束。（52.1 字/句）
```

## 症状 2：用枚举代替论证

**判据**：「A、B、C」三项串联 > 4.5/千字。

**为什么像机器**：把关系写成清单，读者看到的是并列，看不到主次和因果。

```
差：页面、文本块和实体关系并存的检索入口。
好：检索入口有三个，优先级不同：页面优先，页面证据不足时回退到文本块，实体关系只用于扩展相关概念。
```

**拆法**：三项变成"主项 + 次项 + 限定项"，用句子说关系。

---

## 症状 3：结果句没有证据

**判据**：句中有"实验表明/结果表明/测试表明"，但全文无数字。

**为什么像机器**：模型在没有数据时会用一个形容词补位。

```
差：实验结果表明，该系统在电信领域的问答任务中表现出色，显著提高了知识库的应答能力。
好：实验结果表明，主题分割算法在 Wikisection 和 Wiki-50 上，与 CrossSegmentBERT 相比，边界误差分别下降 3.4 和 1 个百分点。
```

**如果确实没测**：改成"该功能在测试用例 T-QA-03 中验证了可用性，性能指标待第 7 章补充"。**不要用形容词假装测过。**

---

## 症状 4：没有责任主体

**判据**："本文"密度 = 0，或全篇主语都是"系统/该模块"。

**为什么像机器**：机器写说明书，人写"我做了什么"。

**改法**：三级回指，同一主语不连用两次——

```
本文提出… → 该方法通过… → 该系统在…上
```

19 篇摘要主语频次：本文 47、该方法 15、本研究 6、该系统 5、我们 0、笔者 0。
**"本文"每千字 1 次**是合理密度；一个没有，或每句都有，都不对。

---

## 症状 5：元话语与语气越位

**判据**：全文搜到这些词——

`需要注意的是` `值得一提的是` `综上所述` `由此可见` `不难发现` `众所周知` `本节将` `笔者` `我们打算` `拟` `目标约` `不宣称` `将在后续研究中`

**为什么像机器**：模型习惯先声明再论述（"下面将从三个方面分析"），人直接给结论。

**改法**：删掉声明，直接写内容。段首需要过渡就用**上一段的末词**开头，不用"此外/同时"。

---

## 症状 6：段落同构

**判据**：段长 CV < 0.35；或连续 3 段都以"本章/本节/该系统"开头；或出现"总—分—总"三连。

**为什么像机器**：模型给每段套同一个模板。

**改法**：让段落承担不同职能——有的段只做举证，有的段只做限定，有的段只做转折。段长 100–350 字之间浮动。

## 附 A：硬空词表（出现即扣分）

```
赋能 助力 极大 大幅 蓬勃 飞速 日益 愈发 至关重要 不可或缺 不可忽视
具有重要意义 发挥重要作用 提供有力支撑 全方位 创新性 先进性 效果良好
表现出色 具有一定的 提供了新思路 具有参考价值 得到了广泛 新范式 新动能
```

**注意**："赋能"不是普适判据。有具体宾语时它是站得住的（"AI 赋能主题式学习服务"）。真正空转的是没有宾语的「数字化浪潮」「全面提升」「打造」。

## 附 B：软程度词（句中有数字才不算空话）

```
显著 有效 全面 充分 迅速 较好 较强 明显 优异 丰富
```

判定规则：这句里有没有数字、基线、数据集。三样都没有，这句就是空话。

## 附 D：一个对照实验（同一段，三种写法）

**原始（AI 味最重）**
> 随着知识管理需求的日益增长，如何高效地构建企业知识库成为了一个重要课题。本文提出的系统有效提升了知识检索的效率和准确性，具有重要的理论意义和实践价值。

问题：背景句无宾语、无数据；结果句无数字；评价句"重要"是自我宣称；整段 65 字 3 句，句长 22/30/24，几乎等长。

**合格**
> 企业知识库的检索效果取决于文档切分是否贴合主题边界。固定长度切分会在章节交界处截断语义，导致召回片段与问题无关。本文按标题层级切分，并在切分后校验每块的主题一致性。

问题：有机制、有因果，但无数字无验证。

**优秀**
> 企业知识库的检索效果取决于文档切分是否贴合主题边界：固定 512 字切分会在章节交界处截断语义，24 篇测试文档中有 11 篇的首块不包含完整的小节标题。本文改为按标题层级切分，切分后校验每块的主题一致性，并在同一批 50 个问题上与固定切分对比，召回率从 0.61 提升到 0.78。

差别只有三处：**给了一个可核验的数字（11/24）、给了对比基线（固定 512 字）、给了结果（0.61→0.78）**。
