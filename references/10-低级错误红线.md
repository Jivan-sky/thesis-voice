# 10 低级错误红线（中文 Word 版）

导师改稿时，真正让他眉头皱起来的往往不是观点，是**同一类小错反复出现**。一处可以改，成批出现传递的信号是"不认真"，那时他会开始怀疑你的认真程度，进而挑更狠的。

**发现一处同类错误，立刻全文检索把同类扫干净。** 这类错误从不单独出现。

## A. 标点

| 错误 | 长什么样 | 怎么改 |
| --- | --- | --- |
| 中文标点后加空格 | `系统需要。 因此` | 删空格 |
| 标点前有空格 | `系统需要 。` | 删空格 |
| 括号前/后缺空格（英文语境） | `Tree(DT)算法` | 中文里全角括号紧跟，英文里 `Tree (DT)` |
| 中英文标点混用 | `状态：running, 完成` | 中文段落用中文标点，英文术语内部用英文标点 |
| 连续标点 | `……。。` / `，，` | 删重复 |
| 引号中西混用 | `"知识页面"`（英文直引号） | 中文用 `“”`，且字体按 `format/本地格式规格.md` |
| 顿号与逗号混用 | 并列项用逗号，句子用顿号 | 并列用「、」，分句用「，」 |
| 省略号写法 | `...` / `。。。` | 中文统一 `……`（六个点） |

## B. 全角 / 半角

| 错误 | 判据 | 怎么改 |
| --- | --- | --- |
| 全角数字 | `１２３` | 全改半角 |
| 全角英文 | `ＡＰＩ` | 全改半角 |
| 括号配对错 | `（RAG)` | 中文括号成对（），英文成对 () |
| 全角横线当破折号 | `系统——即` 用了全角连字符 | 破折号统一 `——`；工科论文全文 ≤2 处 |
| 无空格连接中英 | `使用RAG检索` | 中英之间可加半角空格（按模板要求；模板未要求则不加，但要全文一致） |

## C. 数字与单位

| 错误 | 长什么样 | 怎么改 |
| --- | --- | --- |
| 数字与单位无空格 | `12pt` `3.5cm` | `12 pt` `3.5 cm`（%，° 例外，紧贴） |
| 单位中英混用 | `3.5厘米` 与 `3.5 cm` 并存 | 全文统一一种 |
| 百分比写法不一 | `87.6％`（全角）与 `87.6%` | 统一半角 `%` |
| 千分位 | `1220万字` / `1,220 万字` | 中文里写「约 1220 万字」，数字不加千分位 |
| 范围符号 | `10-20` / `10~20` | 统一 `10～20` 或 `10–20`，按模板 |
| 时间单位 | `1d` `1 s` 混用 | 统一（我们语料里两种都有，选定一种） |

## D. 编号与引用

| 错误 | 怎么查 |
| --- | --- |
| 图表编号跳号或有重号 | 抽出所有「图X-Y」「表X-Y」排序检查 |
| 正文引用与图题编号不一致 | 逐个交叉核对；用 Word 交叉引用避免手打 |
| 公式编号不连续、缺括号 | 统一 `（3-1）` 形式 |
| 参考文献编号与正文上标不一致 | 逐条对；每篇必须被引用至少一次 |
| 参考文献有孤条（正文没引） | 列出现有引用编号，差集就是孤条 |
| 手打编号后又插图 | 全部改为交叉引用，再 F9 更新域 |

## E. 排版与样式

| 错误 | 怎么改 |
| --- | --- |
| 段首用空格缩进 | 用样式里的"首行缩进 2 字符"，删掉手打空格 |
| 用连续回车换页 | 用分页符/分节符；章末分节符不要删 |
| 空行分隔段落 | 删空行，用段前/段后间距 |
| 手动改字体字号 | 只点样式，不改格式 |
| 从网页/PDF 粘贴带入外部格式 | 先"只保留文本"再套样式 |
| 标题里手打"1.1" | 用多级列表自动编号，否则会出现"1.1 1.1 研究背景" |
| 中英文摘要混排字体 | 英文摘要用 Times New Roman，中文用宋体 |
| 图不是矢量/分辨率不足 | 导出 300 dpi；黑白打印可辨认 |
| 表格跨页无表头 | 设置"重复标题行" |

## F. 句子与用词

| 错误 | 判据 | 怎么改 |
| --- | --- | --- |
| 无主语句 | "通过实验验证了…" | 补主语：本文通过实验验证了…… |
| "我们" | 单人课题 | 改"本文" |
| 术语不统一 | 同一概念三种叫法 | 首次给全称+缩写，后文固定 |
| 缩写未定义 | 首次出现无全称 | 补 `（Retrieval-Augmented Generation，RAG）` |
| 慎用词 | 显著/有效/大幅/深远/填补空白/国内领先 | 有数字才留；无数字直接删 |
| 自我宣称 | "首次提出""国际领先""填补空白" | 删；确有检索证据也要先问导师 |
| 一句两件事 | 逗号串起两个独立判断 | 拆句，但保证长句仍存在 |

**为什么这里没有"句子不超过 N 词"**：那是英文期刊的规格。中文实测均句 52.8 字、长句占 40.6%，压短会让论证碎成清单。中文要控的是**句长起伏**，不是句长上限。

## G. 一条命令扫一遍

```bash
python3 scripts/lint_zh.py 章节.md
```

自动查：中文标点后加空格、标点前空格、英文直引号、全角数字/字母、括号配对、连续标点、段首空格、数字与单位间缺空格、慎用词、自我宣称词。

输出按类分组并给行号与原文，改一处就整类扫。

## H. 交稿前最后一遍

1. 全文搜 `"` `'` `...` `。。` `，，` `  `（两个空格）。
2. 全文搜「我们」「首次」「领先」「空白」。
3. 抽出所有图表编号排序，看是否连续。
4. 抽出所有参考文献编号，与正文上标做差集。
5. 用 Word 打开，看批注是否还在、修订是否可见、有无"文档损坏"提示。
6. 另存 PDF，翻一遍奇偶页页眉、目录页码。
