# 06 病灶清单与剂量（工科版）

这一份是把外部参考（humanizer-zh-academic 的 16 模式）拿 41 篇工科语料逐条验过之后的结果。
**结论：16 条里 8 条可用、5 条要改造、3 条不能用在工科论文上。**

## 为什么不能照搬

那份 skill 的语料是社科/人文论文（翻译研究、政策分析），目标是降低 AIGC 检测率。
工科设计与实现类论文的语域不同：

| 特征 | 社科论文 | **工科论文（41 篇实测）** |
| --- | --- | --- |
| 第一人称 | 「笔者」「我」可用 | **0 次**（6 篇学位论文里"笔者""我们认为"合计 0） |
| 破折号 | 适中 | **0.02/千字**（几乎不用） |
| 冒号 | 少 | **4.6–5.1/千字**（靠冒号引出清单与定义） |
| 首先/其次/最后 | 要打破对称 | **1.2/千字**，是合法的结构词 |
| 综上/由此可见 | ≤1 处 | **0.03/千字**，基本不写 |
| 主观表达（"出乎意料的是"） | 加分 | **减分**（导师批注会把这类判为"AI 角度"/多余） |

所以下面分三档处理。

---

## A 档：直接采纳（8 条）

| 病灶 | 判据 | 改法 |
| --- | --- | --- |
| 模糊归因 | 「专家认为」「研究表明」无出处 | 有出处就引；没出处就改成本文自己的判断 |
| 段末总结套句 | 「综上所述」「由此可见」「不难发现」 | 删。**工科语料里这是 0.03/千字，等于不写** |
| 泛化结尾 | 「具有重要意义」「前景广阔」「提供了新思路」 | 删，换成可检验的推论或具体边界 |
| 填充短语 | 「值得注意的是」「需要指出的是」「不难发现」 | 删。实测 0.00–0.01/千字，工科论文不用 |
| 过度限定 | 一句里两个以上"可能/潜在/一定程度的" | 保留一个限定词 |
| 整齐三元并列 | 三项等长、等重 | 改成主项+次项+限定项，或只写两项 |
| 段末"这提示我们" | 引申句 | 改成「既然……那么……」或直接给结论 |
| 加粗滥用 | 正文加粗 >5 处 | 工科论文正文基本不用加粗，全删 |

## B 档：改造后用（5 条）

| 病灶 | 原建议 | **工科版** | 原因 |
| --- | --- | --- | --- |
| 破折号滥用 | 一段 >4 次才减 | **全文 >0.5/千字就减，最好为 0** | 实测 0.02/千字。工科论文用冒号和分号，不用破折号 |
| 冒号过量 | 连续 3 次改破折号 | **冒号保留**，改成"先给类数再列举" | 冒号 4.6/千字是主流写法，改成破折号反而怪 |
| 首先/其次/最后 | 打破对称 | **保留序列词，只打破等长** | 序列词是工科结构标记（1.2/千字），但三段不能一样长 |
| 理论起笔（"基于XX理论"） | 理论名移到段中 | **工科改成"约束起笔"**：先说时延/并发/准确率约束，再说方案 | 工科不引理论，引的是约束与指标 |
| 噪声预算 | 每千字留 2–3 处轻微 AI 特征"抗检测" | **改成防过矫**：不要把所有段落改成同一个腔，允许段落职能不同 | 抗检测是另一件事；防过矫是真实需求 |

## C 档：不能用于工科论文（3 条）

| 病灶 | 原建议 | 为什么不行 |
| --- | --- | --- |
| 注入主观判断 | 「笔者认为」「出乎意料的是」「这里的数据不够理想」 | 工科论文 0 使用率；导师批注会判为"多余""AI 角度"。要用主观判断时，用"本文认为"且只在设计取舍处出现一次 |
| 用反问演示问题 | 「说起来容易，做起来却……」 | 论文不是专栏。工科用陈述句+数据 |
| 插入错别字/口语词提"真实感" | —— | **不要做**。这是应付检测，不是提高质量，且有学术诚信风险 |

**关于"降 AIGC 率"**：那是另一个目标函数，而且和"写好论文"不总是一致。本 skill 只对"像合格的工科论文"负责。检测率不降但论文合格，可以接受；反过来不行。

## 段级剂量硬上限（工科版，实测校准）

千字密度管整体，段级上限管局部。两条都要：

| 项 | 硬上限 | 实测依据 |
| --- | --- | --- |
| AI 高频词（赋能/助力/显著/大幅/深入/全面…） | **每段 ≤2 个** | 学位论文 0.4/千字 |
| 「综上所述 / 由此可见 / 不难发现」 | **全文 0 处** | 0.03/千字 |
| 「值得注意的是 / 需要指出的是」 | **全文 0 处** | 0.00–0.01/千字 |
| 「笔者 / 我们认为」 | **全文 0 处** | 实测 0 |
| 破折号「——」 | **全文 ≤2 处** | 0.02/千字 |
| 正文加粗 | **0 处**（标题除外） | 工科正文不用加粗 |
| 三元并列 | **每段 ≤1 处** | 1.5/千字 |
| 段首同构（连续 3 段同起始词） | **不允许** | —— |

## 改写优先级（病灶排序，不是句子排序）

改一段文字时按这个顺序，前面的不动，后面的白改：

1. **砍尾**——删段末总结句、引申句。
2. **去模糊**——无出处的"研究表明"改成具体引用或本文判断。
3. **破对称**——三元并列改主次；三段等长改成不等长。
4. **补证据**——结果句补数据集/基线/指标/数值；补不上就降级措辞。
5. **调节奏**——长句装机制，短句收束，作者出场句最短。
6. **换词**——最后才动。只换前 8 个高频词（见 `03-句式库.md` 附表）。

**顺序的理由**：前四步是改内容，后两步是改形式。反过来做（先换词）会让病灶留在一段更"自然"的废话里。

## 防过矫（这条比"去 AI 味"更重要）

我们的体检器会推着你把句子拉长、把 CV 拉高。**但过度矫正会变成另一种统一腔**——每段都长句短句、都有数字、都以短句收尾，读起来一样假。

三条约束：

1. **段落要有不同职能**：有的段只举证（全是数据和引用，不评论），有的段只限定（短，两三句），有的段只转折。**不要每段都写成"立论-举证-拆解-限定-收口"五拍全套。**
2. **允许不完美**：全文允许保留 1–2 处"稍平"的过渡段，那是人写作的自然波动。但不要靠故意写错别字或口语来制造波动。
3. **不要每段都怼数字**：绪论背景段、小结段本来就没有数字，这类段落数字密度低是正常的。数字纪律只对结果句和测试章强制。

**判据**：改完后自己读一遍，如果感觉"每段都一个味道"，回去把段落职能岔开，而不是继续调句子。

## 输出格式（改完后按这个交）

```
【体检】均句 X（参考 45–85）｜长句 X% ｜CV X ｜相邻差 X ｜数字/千字 X
【偏离】N 项：…
【高危段】第 X 段：命中〔病灶编号〕，原文「…」
【改写】第 X 段 → 「…」
【改了什么】①砍尾 ②补数字 ③…
【还剩什么】…
```

最后一行不要省。它让导师看到你知道差距在哪，而不是假装改完了。
