## 2. 三个最硬的结论

**（1）句长。** 学位论文平均 53 字/句，你的稿子 32.5 字/句。差 20 字不是"啰嗦"问题——是**一个句子里装不下"条件 + 机制 + 结果"三样东西**。41 篇里没有一篇的均句低于 45。

**（2）起伏。** 相邻句长差 30 字（学位论文）/ 49 字（期刊），你的稿子 14.8 字。**这是"读起来平"的物理来源**，不是用词问题。

**（3）数字与责任主体。** 学位论文每千字 40 个数字，你的**纯正文段里数字为 0**（全部数字都在表格里）。"本文"每千字 1.0 次，你的 0 次。两条合起来就是观感上的"空"——没有主体，没有可核对的东西。

## 4. 软程度词：空话真正藏的地方

"显著 / 有效 / 明显 / 大幅 / 充分"本身可以是实词（"显著优于"配数字时是统计陈述）。判据是**同一句里有没有数字**。

- 学位论文正文：句中有程度词但整句无数字的比例 **1.5 句/千字**（6 篇区间 1.0–2.1）。
- 你的稿子：0.48 句/千字，低于范文——同样不构成问题。

对照样本：

- 孙鸿博（有数字）："与 Cross SegmentBERT 方法相比，边界误差分别下降了 3.4 个百分点和 1 个百分点。"
- 高宇德（无数字）："在各项检索性能指标上均有显著提升。"
